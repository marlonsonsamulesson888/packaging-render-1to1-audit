# 复量默认阈值（可配置）

| 项目 | 默认 | 来源/说明 |
|---|---|---|
| 画布比例 | 10 px/mm（254ppi） | 本厂 1:1 效果图常用；预览用，非印刷分辨率 |
| 餐具头部离窗上/左/右边 | ≥5mm | 开窗盒排布规则；离得太近看起来被窗边切 |
| 相邻件可见净距 | ≥8mm（按需） | 最宽处净距 6mm，照片外框、阴影会吃掉一部分 |
| 装饰离盒顶等折线 | ≥5mm（按实心像素） | 抗锯齿像素另报，不足只提示 |
| 源照片有效分辨率 | ≥300ppi | 低于 300 需负责人批准；只作预览可以 |
| alpha 阈值 | 任意 ≥1，实心 ≥128 | |

## 常见换算
- 有效 ppi = 源图沿长边像素 ÷ (放置长度 mm ÷ 25.4)。例：829px 放 146mm → 144ppi；达到 300ppi 要 1725px。
- 1600×1600 的平台主图里，一支占图高一半的餐具大约 800px，放到 140mm 以上就不到 150ppi，量产前基本都要原始拍摄图。
