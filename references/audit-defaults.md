# 复量默认阈值（可配置）

| 项目 | 默认 | 来源/说明 |
|---|---|---|
| 画布比例 | 10 px/mm（254ppi） | 本厂 1:1 效果图常用；预览用，非印刷分辨率 |
| 餐具头部离窗上/左/右边 | ≥5mm | 开窗盒排布规则；离得太近看起来被窗边切 |
| 相邻件可见区域距离 | 默认不检查阈值；由 `--min-item-gap` 显式指定 | 示例 8mm 仅演示参数，不能作为全厂标准；本脚本按像素中心距离测量 |
| 装饰离盒顶等折线 | ≥5mm（按实心像素） | 抗锯齿像素另报，不足只提示 |
| 源照片有效分辨率 | ≥300ppi | 低于 300 需负责人批准；只作预览可以 |
| alpha 阈值 | 任意 ≥1，实心 ≥128 | |

## 常见换算
- 有效 ppi = 源图沿长边像素 ÷ (放置长度 mm ÷ 25.4)。例：829px 放 146mm → 144ppi；达到 300ppi 要 1725px。
- 1600×1600 的平台主图里，一支占图高一半的餐具大约 800px，放到 140mm 以上就不到 150ppi，量产前基本都要原始拍摄图。

## 三种不同口径
- 单件离窗上/左/右边：脚本 `--min-window-clear` 默认 5mm。
- 整组在窗口内的水平方向左右余量：若项目要求 8mm，须单独核对整组外包范围与窗口，不等于相邻两件距离；脚本没有此专用阈值。
- 名义排布间距：若项目计算表使用 6mm，属于布局参数，不能直接替代照片 alpha 轮廓的测量结果。

相邻可见距离仅取每件 alpha 与窗口蒙版的交集；全图层距离另报。图层缺失可见部分或没有窗口时结果未知并提示，不以隐藏柄部位置推断窗内间距。
